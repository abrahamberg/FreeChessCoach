Walkthrough

Get an OpenAI API key for FreeChessCoach.

About ten minutes, once. You will create an OpenAI Platform account, set a small spending limit, make a key just for this app, and paste it into FreeChessCoach.

Before you start

Read how FreeChessCoach handles your key first if you haven't. The two rules are: use a key made only for this app, and give it a small monthly limit.

The AI coach is optional. Import, stats, game review and the bots work without any of this.

Want to pay nothing?

Follow the steps below, then read the free usage step. OpenAI can give free daily tokens if you let it use your chats to improve its models. It is your choice, and the catch is explained there.

The OpenAI website changes

The names below match OpenAI's console as we last saw it. If a menu has moved, look for the same words nearby.

  1. Create an OpenAI Platform account

    Go to platform.openai.com and sign up, or log in if you already have one. The Platform (for the API) is a separate thing from ChatGPT: a ChatGPT subscription does not include API credit, and API usage is billed on its own.

  2. Add a little credit

    In the left menu open Billing, add a payment method, and buy a small amount of prepaid credit. $5 is a sensible start. OpenAI's Limits page also shows that purchasing about $5 moves you up from the free tier to Tier 1, which raises your rate limits.

    You choose the amount, and you can stop any time. We never see your payment details, since they are entered on OpenAI's site.

  3. Set a spending limit (the most important step)

    Open Limits in the left menu. Under Spend you will see the Organization spend limit. Choose Edit spend limit and set it to a small monthly amount, for example $5.

    While you are there, use Add alert under Spend alerts to get an email at 80% and at 100% of that limit. OpenAI notes that your actual costs may exceed a limit depending on usage, so keep it small.

    After a couple of weeks, check Usage and adjust the limit to what you really use.

  4. Optional: make a project just for FreeChessCoach

    Open Projects and create one named FreeChessCoach. Keeping this app in its own project makes its usage easy to see and its key easy to remove, without touching anything else you run.

  5. Create a key only for this app

    Open API keys and choose Create new secret key. In the box that opens:

    • Owned by: leave it on You.
    • Name: something like FreeChessCoach, so you remember what it is for.
    • Project: the FreeChessCoach project from the last step, if you made one.
    • Expiration: pick a date a few months away if it offers one. A key that expires on its own is a key you will rotate.

    Then choose Create secret key. OpenAI shows the key once. Copy it now. If you lose it, you simply make another.

    Treat the key like a password. Never post it in a chat, screenshot or public repository. If it is ever exposed, delete it in API keys (the bin icon beside it) and make a new one.

  6. Paste it into FreeChessCoach

    Prefer not to use a cloud key? Run a model on your own computer instead.

    Sign in to FreeChessCoach and open Settings, then the AI setup section. It is a short two-step wizard.

    Step 1: Connect your AI.

    • API URL: leave https://api.openai.com/v1.
    • API key: paste your key.
    • Low model / High model / Voice model: the form is pre-filled with the defaults the app recommends. Leave them unless you know you want something else. The voice model is optional.
    • Use OpenAI Flex processing: about half the token price, but responses are slower and can occasionally be unavailable. Ticked by default for a new setup; untick it if you prefer speed.

    Choose Test connection. The app makes a tiny test call for each model and shows what it found. If it passes, choose Proceed.

    Step 2: Set an unlock phrase. Pick a phrase of at least 8 characters that you don't use anywhere else, then Save. Your key is encrypted with it, and we can't recover it if you forget it.

    Later, Enter unlock phrase unlocks the setup for a coaching session, Lock now removes the decrypted copy from our server straight away, Replace setup is how you rotate to a new key, and Delete setup removes it.

  7. Optional: complimentary daily tokens, and what they cost you in privacy

    OpenAI has a data-sharing setting that can make some usage free. You can see it at Settings → Data controls → Sharing, under Share inputs and outputs with OpenAI. When it is on, OpenAI's console tells you that you are enrolled for complimentary daily tokens.

    Please read what this means before you turn it on. OpenAI says the traffic you send once it is enabled is shared to help it develop and improve its services, including training its models. For FreeChessCoach, that traffic is your games and your conversations with the coach.

    It is your choice, and you can change it at any time. If you do enable it, consider Enabled for selected projects and pick only the FreeChessCoach project, so nothing else you run with OpenAI is included. Check OpenAI's own page for the current terms and the amount of free tokens, since we don't control them.

  8. Rotate it every so often

    Every month or two, or when the key expires: make a new key as above, use Replace setup in FreeChessCoach, then delete the old key in API keys. That is the whole routine.

Or run the AI on your own computer

No account, no key and no cost per message. The coach can use a model served by LM Studio or Ollama on your machine. Your computer needs to be able to run the model you pick, and small models can coach less reliably than a cloud one.

  1. Start your local server

    LM Studio: download a model, open the Developer tab, start the server and turn on Enable CORS in its server settings, so this site may call it. Ollama: set OLLAMA_ORIGINS to include this site's address and restart Ollama.

  2. Connect it in Settings

    Open Settings → AI setup, choose On my computer (LM Studio / Ollama), pick your server type and check the Local API URL. Choose your model (the form lists what your server offers), then Test connection. The test also warns if the model's context window is under 16k tokens, which is about what the coach needs. A token is only needed if your server asks for one.

  3. Keep the tab open while you coach

    Our server cannot reach your computer directly, so each request goes through your open browser tab to your local server and back. If you close the tab or stop the server, the coach pauses. A local server answers one request at a time, so replies may take longer than from a cloud service.
